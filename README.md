# skills-map-2027
This on-line page allows organisations to rank a list of the top 10 marketing skills for 2027 based on LinkedIn, WEF, McKinsey, Gartner, Forrseter, PwC and Accenture marketing skill predictions for 2026.
Users sequence a provided set of 10 skills according to their strategic priorites.
For each skill they then assess their team's current coverage.
0 - no one on the team has the skill to 10 - every member has 100% compentence.
The results are shown in a map.
The map and ranking can be downloaded in an XL spreadsheet.
